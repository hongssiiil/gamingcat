# 9개 장면 별자리 엔딩

## 실제 데이터 연결

노드는 항상 `암호 찾기 → 갈림길 1~5 → 퍼즐 1 → 퍼즐 2 → 해적 전투` 순서의 9개다. 개별 행동 수가 늘어나도 노드 수는 변하지 않는다. 기록이 없는 노드는 흐린 별이며 선택하면 `아직 이 장면의 기록이 없어요`를 표시한다.

- 암호: `events`의 `password-solved`로 완료를 확인한다. 없으면 `notes`와 `note` 이벤트의 중복 없는 단서 수를 사용한다. 게임 단계만으로 완료를 추정하지 않는다.
- 갈림길: `choices[].scene`의 `fork-1`~`fork-5`로 묶는다. `options`, `selected`, `recommended`가 비교 가능한 기록만 분모에 넣고 같은 선택인 경우만 분자에 넣는다. 예전 `scene` 없는 기록은 배열 순번으로 연결한다. 기존 게임은 보통 갈림길당 1회 선택을 저장하므로 `1 / 1`, `0 / 1`이 정상이며 2 / 3 같은 값을 임의 생성하지 않는다.
- 퍼즐 1/2: 각각 `pond`, `climb`에 대응한다. `completed` 또는 `puzzle-complete` 이벤트로 완료를 확인하고, 미완료라면 `pondTrail` / `climbTrail`에 남은 실제 칸 수만 보여준다. 과거 암호·퍼즐 실패 횟수는 저장되지 않았으므로 생성하지 않는다.
- 전투: `battleHistory`의 실제 선택 턴들을 하나의 노드에 묶는다. 마지막 결과 또는 전투 종료 이벤트의 `victory`, `escape`, `defeat`를 사용한다. 도주일 때만 9번째 별을 검게 표시한다. 패배의 기존 재전투 흐름은 유지하면서 이후 요약을 위해 패배 결과도 턴에 저장한다.

`getEndingJourney()`와 개발용 `ending-preview.html` 모두 단서·퍼즐 상태까지 동일한 어댑터에 전달한다. 별자리 이름은 기존 실제 선택 로그 기반 규칙을 유지한다. 토큰은 실제 도움 로그와 누적 helpCount 증가분을 사용하며 숲 도움을 첫 갈림길 사용으로 중복 표시하지 않는다.

## 화면·인터랙션

기존 전체 화면 배경, 얇은 픽셀 버튼 및 작은 하단 팝업을 유지한다. 기본 문구는 제공된 DungGeunMo, 제목·강조 문구는 NeoDGMCode 웹폰트를 사용하며 Canvas 지도와 저장 이미지에도 동일하게 적용한다. 지정 PNG를 복사한 `images/ending/night-sky.png`를 사용한다. 화면 변경 시 배경과 고정된 9개 좌표의 클릭 영역을 함께 계산한다. 제목은 상단 중앙 텍스트이며 배경 프레이밍은 소녀·고양이·망원경을 보존한다.

44px 버튼은 장면명과 상태를 접근성 라벨에 포함한다. 방향키는 포커스 이동, Enter/Space는 선택이다. 클릭하면 즉시 해당 노드 요약이 표시된다. 포커스와 선택 표시를 구분한다. 닫기/Escape는 팝업을 닫고 별로 포커스를 돌린다. 긴 기록은 작은 팝업 안에서만 스크롤한다.

## 등장 연출

총 4.2초: 0~400ms 어두워짐, 400~850ms 중앙 픽셀 모으기, 850~3650ms 1~9번 경로와 별 조립, 3650~4200ms 약한 밝기 마무리. 계단형 선의 진행 지점에 정사각 픽셀 조각이 따라가며 최근 선은 바랜 금색에서 은빛으로 바뀐다. 별은 셀들이 각 위치로 모여 완성되며 크기 팝 효과는 없다. 모션 감소 설정은 이동 없이 250ms 페이드만 사용한다. 입력하면 즉시 완성 상태로 전환한다. 화면 이탈 시 RAF와 ResizeObserver를 정리한다.

PNG는 배경·완성된 9개 별자리·이름만 저장한다. 조작 UI와 선택 표시·팝업은 제외한다. 처음으로는 기존 확인창과 Road freshState·전투 초기화를 사용한다.

## 검증

```sh
node --test script/ending.test.mjs script/road/*.test.mjs
node --experimental-vm-modules --test script/battle-ending.test.mjs
git diff --check
```

49개 엔딩/Road 테스트와 3개 전투 제어기 테스트 통과. 브라우저에서 정확한 9개 노드, 미진행 안내, 실제 저장된 도주 기록, 검증용 2 / 3 추천 집계, 암호 완료와 퍼즐 완료/부분 진행, 승리 시 일반 별을 확인했다. 연출 단계는 실제 브라우저에서 약 403ms, 872ms, 3670ms, 4205ms에 전환됐다. 초기 입력 시 169ms에 완료 상태가 됐다. 모션 감소는 이동 단계 없이 페이드로 표시됐다. 360×800 CSS px에서 문서 크기가 뷰포트와 같았다. 전체 숲 탐험부터 전투까지의 수동 완주는 하지 않았다.

검증용 임시 픽스처는 제거한다. `ending-preview.html`은 현재 탭 sessionStorage의 실제 저장 기록만 보여주며 예시 데이터를 생성하지 않는다.
