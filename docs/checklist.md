# gaming cat — 확인 체크리스트

## 사용 장면

- [ ] 1단계: 링크를 열면 게임 소개와 시작 동작이 있는 시작 화면이 보인다.
- [ ] 1단계: 계정 생성 없이 게임을 시작할 수 있다.
- [ ] 2단계: 고양이, 갈림길 질문, 선택 가능한 길이 보이고 선택하면 다음 장면으로 진행된다.
- [ ] 2단계: 고양이 아이콘과 퍼져 있는 고양이 아이콘이 표시된다.
- [ ] 3단계: 매 턴 AI 고양이의 추천 행동과 사용자가 고를 행동이 표시된다.
- [ ] 3단계: 공격·도망·아이템 사용을 선택할 수 있고 체력·피해 변화와 전투 결과가 반영된다.
- [ ] 4단계: 지금까지의 선택 결과가 숲의 분위기에 시각적으로 나타난다.
- [ ] 5단계: 마지막 화면에서 이번 여정의 선택 경로가 별자리 형태로 보인다.
- [ ] 5단계: 회고 내용은 선택을 보여주며 주체성이나 AI 의존도를 점수화하거나 판정하지 않는다.
- [ ] 5단계: 다시 시작하면 새 여정을 진행할 수 있다.

## 알파 테스트

- [ ] AI를 사용하는 친구 3명에게 “선택해 보세요”라고 안내하고, 생각을 말하도록 유도하지 않는다.
- [ ] 3명 중 2명 이상이 시작부터 마지막까지 진행을 완료한다.
- [ ] 사용자가 AI 추천과 다른 행동을 선택할 수 있고, 그 선택이 진행에 반영된다.
- [ ] 테스트 중 진행을 막는 문제와 회고 화면에서 선택 흐름을 이해했는지 기록한다.
