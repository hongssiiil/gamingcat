# 커밋 메시지 형식

제목만 읽어도 변경 사항을 알 수 있게 짧고 구체적으로 작성합니다. 한 커밋은 한 종류의 변경을 담습니다.

```text
<type>: <변경 내용>
```

사용 가능한 `type`:

- `feat`: 기능 추가
- `fix`: 오류 수정
- `docs`: 문서 변경
- `style`: 동작 변경 없는 스타일 수정
- `refactor`: 기능 변경 없는 코드 구조 개선
- `chore`: 설정·도구·기타 유지보수

예시:

```text
feat: 갈림길 선택에 따라 다음 장면 표시
fix: 아이템이 없을 때 전투 진행 유지
docs: 공동 작업 규칙 추가
```
