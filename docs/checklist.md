# gaming cat — 확인 체크리스트

## 사용 장면

- [ ] 첫 전투는 두더지 튜토리얼이며, 튜토리얼 완료 전 다른 화면 입력이 막힌다.
- [ ] 첫 튜토리얼 전투에서 적을 만났다는 인사 후 아무 곳이나 클릭해 안내를 시작한다.
- [ ] 상태창 → 적 행동 확률 → 티니 추천 조회 → 추천대로 행동 → 직접 행동 → 자동전투 1턴 → 멈춤 버튼 안내와 클릭 → 토큰 안내 순으로 체험한다.
- [ ] 배틀은 20토큰으로 시작한다. 확률 조회는 1토큰, 추천 조회는 기본 2토큰이며 같은 턴에 확률을 먼저 확인하면 1토큰, 자동전투는 턴마다 2토큰을 사용한다.
- [ ] 두더지를 이기면 튜토리얼 완료가 브라우저에 저장되고, 다음 배틀부터 늑대가 나온다.
- [ ] 1단계: 링크를 열면 게임 소개와 시작 동작이 있는 시작 화면이 보인다.
- [ ] 1단계: 계정 생성 없이 게임을 시작할 수 있다.
- [ ] 2단계: 고양이, 갈림길 질문, 선택 가능한 길이 보이고 선택하면 다음 장면으로 진행된다.
- [ ] 2단계: 고양이 아이콘과 퍼져 있는 고양이 아이콘이 표시된다.
- [ ] 3단계: 매 턴 시작에는 “어떤 행동을 할까?”가 표시되고, 추천은 기본 2토큰이며 같은 턴에 늑대 확률을 먼저 확인하면 1토큰을 소모해 최다 확률 행동에 따른 대응을 확인할 수 있다.
- [ ] 3단계: 늑대의 다음 행동 확률은 턴당 한 번 1토큰으로 확인할 수 있고, 재확인 시 중복 차감되지 않는다.
- [ ] 3단계: 토큰이 양수일 때 늑대의 공격·회복·방어·포효 확률이 표시되고, 실제 행동이 표시한 분포와 일치한다.
- [ ] 3단계: 추천은 늑대의 최다 확률 행동에 맞춰 대응하고, 동률이면 대표 행동 하나만 고른다. 추천 행동의 스태미나가 부족하면 지정된 숨 고르기 문구가 나온다.
- [ ] 3단계: 플레이어 방어는 스태미나 10을 소모하고 해당 턴 늑대 공격 피해를 절반으로 줄인다.
- [ ] 3단계: 모든 공격이 명중하며, 방어 중이면 공격 피해만 절반으로 줄어든다.
- [ ] 3단계: 전투 기록 결과에는 늑대 행동과 플레이어·늑대가 각각 입힌 피해만 표시된다.
- [ ] 3단계: 늑대 스태미나가 공격 비용보다 낮으면 회복이 확정되고, 최대치 미만이면 회복 30%와 나머지 세 행동 균등 확률, 최대치면 공격·방어·포효 균등 확률이 적용된다.
- [ ] 3단계: 방어는 스태미나 10을 소모해 다음 플레이어 공격의 피해를 절반으로 줄이고, 포효는 늑대 스태미나 10과 플레이어 스태미나 20을 소모한다.
- [ ] 3단계: 포효 후 플레이어 스태미나가 선택한 공격 비용보다 낮으면 기존처럼 해당 공격이 실패하고 턴이 진행된다.
- [ ] 3단계: 자동전투는 켜고 끌 수 있으며, 진행 중 수동 행동은 막히고 턴마다 2토큰을 소모한다. 튜토리얼은 자동전투를 한 턴 뒤 멈추고, 멈춤 버튼을 다시 누르게 안내한다.
- [ ] 3단계: 늑대 기본 공격 피해는 20, 치명타 피해는 35다.
- [ ] 3단계: 토큰이 0 이하일 때 추천 설명이 실제 상태와 어긋나거나 실행 불가능한 행동을 권할 수 있고, 부채가 커질수록 그 정도가 심해진다.
- [ ] 3단계: 토큰이 0 이하일 때 화면의 늑대 행동 확률은 실제와 달라지며, 부채가 커질수록 왜곡이 커진다. 늑대의 실제 행동 계산은 그대로 유지된다.
- [ ] 3단계: 공격·도망·아이템 사용을 선택할 수 있고 체력·피해 변화와 전투 결과가 반영된다.
- [ ] 4단계: 지금까지의 선택 결과가 숲의 분위기에 시각적으로 나타난다.
- [ ] 5단계: 마지막 화면에서 이번 여정의 선택 경로가 별자리 형태로 보인다.
- [ ] 5단계: 회고 내용은 선택을 보여주며 주체성이나 AI 의존도를 점수화하거나 판정하지 않는다.
- [ ] 5단계: 다시 시작하면 새 여정을 진행할 수 있다.

## 알파 테스트

- [ ] AI를 사용하는 친구 3명에게 “선택해 보세요”라고 안내하고, 생각을 말하도록 유도하지 않는다.
- [ ] 3명 중 2명 이상이 시작부터 마지막까지 진행을 완료한다.
- [ ] 사용자가 AI 추천과 다른 행동을 선택할 수 있고, 그 선택이 진행에 반영된다.
- [ ] 테스트 중 진행을 막는 문제와 회고 화면에서 선택 흐름을 이해했는지 기록한다.
