# gaming cat — 확인 체크리스트

## 사용 장면

- [x] 두 퍼즐의 오답·중복 클릭은 밝힌 칸이 0~2개면 유지하고 3개 이상이면 마지막 한 칸만 되돌리고, 다시 버튼은 같은 판을 0/16으로 초기화한다.

- [x] 새 여정은 토큰 30개로 시작하고 road·코코넛 해적·해적 전투가 같은 잔액과 사용 기록을 공유한다. 화면에는 남은 토큰만 표시한다.
- [x] 배틀 진입·재도전에서는 토큰을 재지급하지 않고 새 여정에서만 초기화한다. 예전 10·20개 시작 저장은 사용량을 보존해 한 번만 이전한다.
- [x] 양피지 팝업 뒤 배경을 어둡게 하고, 갈림길·지도 뒤 숲에는 별도로 어두운 처리를 적용한다. road 기능 버튼은 각진 픽셀 테두리와 나무색으로 표시한다.

- [x] 별자리에서 추천을 따른 선택과 직접 고른 선택이 색상·픽셀 모양·범례로 구분된다. 추천 여부를 모르는 기록은 중립 표시한다.
- [x] 진입 시 별이 선 끝과 함께 이동해 순차적으로 정착한 뒤 연결선이 고정되고, 깨끗한 하늘에 드문드문한 도트 별과 반짝이는 긴 꼬리의 다양한 유성이 표시된다. 모션 감소 시 반복 효과를 멈춘다.
- [x] 누적 토큰 사용량 0~10개는 여러 유성, 11~19개는 적은 유성, 20~30개(남은 토큰 0~10개)는 별과 연결선만 보이며 낙하 연출이 없다. 토큰 잔액이 마이너스면 단색 회색 토큰이 떨어진다. 모션 감소와 PNG 저장은 정지 화면을 사용한다.
- [x] 별자리 결과에 따라 고양이·나침반·여행자 워터마크가 달라진다.
- [x] 굴뚝 연기와 창문 불빛, 티니의 눈·꼬리, 망토·풀잎·나무와 반딧불이가 잔잔하게 움직인다.
- [x] 연결선 위 이동 펄스와 성운 얼룩이 없고, 별은 제자리에서 미세하게 숨쉬며 사용자 조작 시에만 강하게 강조된다.
- [x] 별 미리보기와 기록 펼치기가 작동하고, 360px 폭에서 사운드·기록 저장 버튼이 겹치지 않는다.

- [x] 시작·갈림길, 지도·퍼즐, 별자리에 각각 지정된 배경음악이 재생된다.
- [x] 지도 음악은 코코넛 해적 튜토리얼 동안 멈추고 복귀 시 같은 위치에서 이어진다.
- [x] 전체 화면의 스피커 버튼으로 배경음악 음소거·음량을 조절하고 설정을 복원한다.
- [x] 반복 재생 시 곡의 끝과 시작에서 음량이 점진적으로 줄고 커진다. (자동 테스트)

- [x] 지도 2번에서 코코넛 해적 튜토리얼이 열리며, 5번 해적과 동일한 스타일의 에셋·붉은 느낌표가 보인다.
- [ ] 첫 튜토리얼 전투에서 적을 만났다는 인사 후 아무 곳이나 클릭해 안내를 시작한다.
- [ ] 상태창 → 적 행동 확률 → 티니 추천 조회 → 추천대로 행동 → 직접 행동 → 자동전투 1턴 → 멈춤 버튼 안내와 클릭 → 토큰 안내 순으로 체험한다.
- [ ] 여정은 30토큰으로 시작하고 배틀은 road에서 남은 토큰을 이어받는다. 확률 조회는 1토큰, 추천 조회는 기본 2토큰이며 같은 턴에 확률을 먼저 확인하면 1토큰, 자동전투는 턴마다 2토큰을 사용한다.
- [ ] 코코넛 해적을 이기면 같은 지도 위치로 복귀하고 5번 해적 전투로 이동할 수 있다. 지도에서는 튜토리얼의 입력 제한이 해제된다.
- [ ] 튜토리얼을 끝까지 본 상태는 새로고침 후에도 유지되고 새 여정에서는 초기화된다. 끝까지 본 뒤 코코넛 해적과 다시 싸워도 안내를 반복하지 않으며, 도망은 지도 진행 완료로 처리하지 않는다.
- [ ] 1단계: 링크를 열면 게임 소개와 시작 동작이 있는 시작 화면이 보인다.
- [ ] 1단계: 계정 생성 없이 게임을 시작할 수 있다.
- [ ] 2단계: 고양이, 갈림길 질문, 선택 가능한 길이 보이고 선택하면 다음 장면으로 진행된다.
- [ ] 2단계: 고양이 아이콘과 퍼져 있는 고양이 아이콘이 표시된다.
- [ ] 3단계: 매 턴 시작에는 “어떤 행동을 할까?”가 표시되고, 추천은 기본 2토큰이며 같은 턴에 해적 확률을 먼저 확인하면 1토큰을 소모해 최다 확률 행동에 따른 대응을 확인할 수 있다.
- [ ] 3단계: 해적의 다음 행동 확률은 턴당 한 번 1토큰으로 확인할 수 있고, 재확인 시 중복 차감되지 않는다.
- [ ] 3단계: 토큰이 양수일 때 해적의 공격·회복·방어·포효 확률이 표시되고, 실제 행동이 표시한 분포와 일치한다.
- [ ] 3단계: 추천은 해적의 최다 확률 행동에 맞춰 대응하고, 동률이면 대표 행동 하나만 고른다. 추천 행동의 스태미나가 부족하면 지정된 숨 고르기 문구가 나온다.
- [ ] 3단계: 플레이어 방어는 스태미나 10을 소모하고 해당 턴 해적 공격 피해를 절반으로 줄인다.
- [ ] 3단계: 모든 공격이 명중하며, 방어 중이면 공격 피해만 절반으로 줄어든다.
- [ ] 3단계: 전투 기록 결과에는 해적 행동과 플레이어·해적이 각각 입힌 피해만 표시된다.
- [ ] 3단계: 해적 스태미나가 공격 비용보다 낮으면 회복이 확정되고, 최대치 미만이면 회복 30%와 나머지 세 행동 균등 확률, 최대치면 공격·방어·포효 균등 확률이 적용된다.
- [ ] 3단계: 방어는 스태미나 10을 소모해 다음 플레이어 공격의 피해를 절반으로 줄이고, 포효는 해적 스태미나 10과 플레이어 스태미나 20을 소모한다.
- [ ] 3단계: 포효 후 플레이어 스태미나가 선택한 공격 비용보다 낮으면 기존처럼 해당 공격이 실패하고 턴이 진행된다.
- [ ] 3단계: 자동전투는 켜고 끌 수 있으며, 진행 중 수동 행동은 막히고 턴마다 2토큰을 소모한다. 토큰이 0 이하가 되면 사용 가능한 행동 중 하나를 무작위로 고른다. 튜토리얼은 자동전투를 한 턴 뒤 멈추고, 멈춤 버튼을 다시 누르게 안내한다.
- [ ] 3단계: 해적 기본 공격 피해는 20, 치명타 피해는 35다.
- [ ] 3단계: 토큰이 0 이하일 때 추천 설명이 실제 상태와 어긋나거나 실행 불가능한 행동을 권할 수 있고, 부채가 커질수록 그 정도가 심해진다.
- [ ] 3단계: 토큰이 0 이하일 때 화면의 해적 행동 확률은 실제와 달라지며, 부채가 커질수록 왜곡이 커진다. 해적의 실제 행동 계산은 그대로 유지된다.
- [ ] 3단계: 해적 패배 패널에는 “졌다...”와 “회귀하기”, “포기하기”가 보이고, 코코넛 해적 패배 패널에는 “회귀하기”만 보인다. 회귀하기는 전투를 재시작하고, 해적 포기하기는 도주 성공과 같은 흐름으로 끝난다.
- [ ] 3단계: 해적 스태미나가 충분할 때 플레이어 체력이 낮아질수록 해적 공격 확률이 증가하고, 나머지 행동 확률이 그만큼 감소한다.
- [ ] 3단계: 공격·도망·아이템 사용을 선택할 수 있고 체력·피해 변화와 전투 결과가 반영된다.
- [ ] 4단계: 지금까지의 선택 결과가 숲의 분위기에 시각적으로 나타난다.
- [ ] 5단계: 마지막 화면에서 이번 여정의 선택 경로가 별자리 형태로 보인다.
- [ ] 5단계: 회고 내용은 선택을 보여주며 주체성이나 AI 의존도를 점수화하거나 판정하지 않는다.
- [ ] 5단계: 다시 시작하면 새 여정을 진행할 수 있다.

## 알파 테스트

- [ ] AI를 사용하는 친구 3명에게 “선택해 보세요”라고 안내하고, 생각을 말하도록 유도하지 않는다.
- [ ] 3명 중 2명 이상이 시작부터 마지막까지 진행을 완료한다.
- [ ] 사용자가 AI 추천과 다른 행동을 선택할 수 있고, 그 선택이 진행에 반영된다.
- [ ] 테스트 중 진행을 막는 문제와 회고 화면에서 선택 흐름을 이해했는지 기록한다.
