# gaming cat — 요구사항

## 1. 프로젝트 개요

- **이름:** gaming cat
- **형태:** AI 고양이와 함께 이야기를 따라가며 선택하고 전투를 진행하는 인터랙티브 웹 게임
- **핵심 질문:** AI를 사용하는 사람이 자신의 AI 사용을 점검하고 싶을 때, AI와 여러 선택을 하나씩 해 나가면 스스로 선택하고 있다는 주체성을 느낄 수 있을까?
- **목표:** 사용자가 AI의 제안을 그대로 따르거나 거절하는 경험을 직접 선택으로 만들어 보고, 마지막에 여정의 선택 기록을 돌아보게 한다. 이 게임은 주체성을 입증하거나 점수화하기보다 사용자의 성찰을 돕는 경험을 제공한다.

## 2. 대상 사용자와 사용 맥락

- AI를 사용하면서 자신의 선택 방식이나 AI의 영향력을 돌아보고 싶은 사람
- 별도의 계정이나 긴 안내 없이 짧은 플레이를 통해 선택 경험을 해 보고 싶은 사람

## 3. 핵심 경험 흐름

1. 사용자가 시작 화면에서 게임을 시작한다.
2. AI 고양이가 여정의 배경과 현재 상황을 소개한다.
3. 이야기의 갈림길에서 사용자가 선택지를 고른다. 선택 결과에 따라 다음 장면과 여정의 기록이 달라진다.
4. 갈림길의 적을 만나면 턴제 전투로 진행한다. AI 고양이는 행동을 제안하고, 사용자는 행동을 선택한다.
5. 지금까지의 선택이 숲의 분위기와 시각 요소에 누적 반영된다.
6. 여정이 끝나면 선택 경로를 별자리 형태로 보여 주고, 사용자가 자신의 여정을 돌아본다.

## 4. 기능 요구사항

### 4.1 시작 및 안내

- 시작 화면은 게임의 이름, 짧은 소개, 시작 동작을 제공한다.
- 게임의 목적과 조작 방법을 짧게 안내한다.
- 알파 버전은 계정 생성 없이 플레이할 수 있다.

### 4.2 갈림길과 이야기

- AI 고양이 캐릭터가 화면에 등장하며 상황에 맞는 표정 또는 상태를 표시한다.
- 사전에 작성된 이야기 장면과 선택지를 제공한다.
- 선택지는 한 번에 읽고 비교할 수 있는 문장으로 표시한다.
- 사용자가 선택하면 해당 선택과 연결된 다음 장면으로 진행한다.
- 플레이 중 되돌아가기나 다시 시작 동작을 제공한다.
- **알파 범위:** 실제 생성형 AI 호출 없이 미리 작성된 대사와 분기 데이터를 사용해도 된다. 화면에서 AI의 선택 제안을 나타낼 경우, 사용자가 이를 따르거나 다른 행동을 고를 수 있어야 한다.

### 4.3 턴제 전투

- 전투는 플레이어와 적이 번갈아 행동하는 턴제 방식이다.
- 플레이어와 적의 체력을 표시하고, 체력 변화가 행동 결과에 반영된다.
- 매 플레이어 턴에 사용자는 최소한 공격, 도망, 아이템 사용 중 가능한 행동을 선택할 수 있다.
- AI 고양이의 추천 행동을 표시하되, 플레이어가 직접 다른 행동을 선택할 수 있다.
- 전투 결과에 따라 승리, 도주 또는 게임 종료 상태를 분명하게 안내하고 이야기로 연결한다.
- 체력이 0 이하가 되는 상황과 아이템이 없는 상황을 포함해 행동 불가 상태를 처리한다.

### 4.4 선택 누적과 숲의 변화

- 갈림길과 전투에서 사용자가 실제로 선택한 행동을 세션 동안 기록한다.
- 주요 선택은 숲의 색감, 밝기, 식생 등 눈에 보이는 분위기 변화에 반영한다.
- 같은 선택을 반복하거나 추천을 따르는 것에 대해 보상·벌점으로 낙인찍지 않는다.
- 분위기 변화가 어떤 선택에서 비롯됐는지 사용자가 여정 기록에서 확인할 수 있다.

### 4.5 여정 회고와 별자리

- 마지막 화면은 선택 순서를 별자리 또는 별자리 지도와 같은 시각화로 보여 준다.
- 각 별 또는 지점은 여정의 선택을 나타내고, 선택 순서가 선이나 배치로 읽혀야 한다.
- 사용자가 지점이나 기록을 선택하면 해당 장면과 자신이 고른 행동을 확인할 수 있다.
- 요약은 플레이어가 한 선택을 설명하는 데 그치며, 주체성이나 AI 의존도를 평가하는 판정·점수를 만들지 않는다.
- 다시 시작 동작을 제공한다.
- **후순위:** 이미지 다운로드, 링크 공유. 알파에서 구현할 경우 개인정보 없이 동작하도록 한다.

## 5. 비기능 요구사항

- 데스크톱과 모바일 화면에서 핵심 진행과 선택이 가능해야 한다.
- 버튼과 선택지는 키보드로 조작할 수 있고, 현재 포커스를 알아볼 수 있어야 한다.
- 체력과 진행 상태는 색만으로 구분하지 않는다.
- 긴 텍스트를 피하고, 이야기·전투·회고의 현재 상태를 명확히 표시한다.
- 알파 버전은 플레이 데이터를 서버에 전송하거나 저장하지 않고 브라우저 세션 안에서 처리한다.
- 새로고침 또는 재시작 후 이전 선택 기록은 초기화되어도 된다.

## 6. 알파 버전 범위

### 꼭 구현

- 시작 화면과 기본 안내
- 고양이 캐릭터 표시
- 완주 가능한 짧은 이야기와 최소 한 번의 갈림길
- 턴제 전투, 플레이어 체력, 적 체력, 공격·도망·아이템 행동
- 갈림길 및 전투 선택 기록
- 선택에 반응하는 숲의 시각적 분위기
- 선택 경로를 확인하는 별자리형 마지막 화면
- 게임 다시 시작

### 알파 이후 또는 있으면 좋은 것

- 추가 갈림길, 적, 아이템, 행동 종류
- 전투 중 체력 변화에 따른 별도 연출이나 효과
- 더 다양한 고양이 표정과 이야기 대사
- 여정 이미지 저장 및 공유
- 로그인, 사용자 데이터 저장, 실제 생성형 AI 연동

## 7. 성공 기준 및 확인 질문

- 처음 방문한 사용자가 별도 설명 없이 시작부터 회고 화면까지 완주할 수 있다.
- 사용자가 전투에서 추천 행동과 다른 행동을 선택할 수 있고 그 결과가 진행에 반영된다.
- 회고 화면에서 각 주요 선택의 순서와 결과를 알아볼 수 있다.
- 플레이 후 사용자가 자신의 선택을 돌아볼 수 있는 질문을 제공한다. 예: “AI의 제안을 따른 순간과 바꾼 순간은 어디였나요?”
- 주체성에 대한 결론은 제품이 대신 내리지 않고, 알파 사용성 확인을 통해 탐색한다.
