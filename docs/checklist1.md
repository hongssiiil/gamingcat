# 확인 체크리스트

- [ ] 1단계: 링크를 열면 ChatGPT와 비슷한 UI의 시작 화면이 보인다.
- [ ] 2단계: 갈림길 질문과 선택 가능한 길이 보이고, 선택하면 플레이어가 숲속으로 나아간다.
- [ ] 2단계: 고양이 아이콘과 퍼져 있는 고양이 아이콘이 표시된다.
- [ ] 3단계: 매 전투 턴에 AI 추천 행동과 사용자가 고를 행동이 표시된다.
- [ ] 3단계: 공격·도망가기·아이템 사용을 선택할 수 있고, 체력과 피해량 변화 및 전투 결과가 보인다.
- [ ] 4단계: 지금까지 쌓인 선택의 결과가 숲의 분위기로 나타난다.
- [ ] 5단계: 마지막 화면에서 이번 여정의 선택 기록이 별자리 형태로 보인다.
- [ ] 알파 테스트: AI를 사용하는 친구 3명에게 “선택해 보세요”라고 안내하고, 생각을 말하도록 유도하지 않는다.
- [ ] 알파 테스트: 3명 중 2명 이상이 처음부터 마지막까지 진행을 완료한다.
- [ ] 공통: 콘솔 오류 없음 · 360px 폭에서 가로 스크롤 없음 · 버튼은 button, 이미지에는 alt.
