# gaming cat — 작업 목록

## 1. 기획 및 구조

- [ ] 알파 플레이의 시작과 끝을 포함한 짧은 스토리 구조 작성
- [ ] 갈림길 장면, 선택지, 선택별 결과 작성
- [ ] AI 고양이의 역할과 추천 표시 방식 정리
- [ ] 전투 규칙 확정: 체력, 공격력, 적 행동, 도주, 아이템, 승패 조건
- [ ] 선택 기록 데이터와 숲 분위기 변화 규칙 정의
- [ ] 별자리 화면에서 선택을 배치하고 연결하는 규칙 정의

## 2. 화면 및 시각 디자인

- [ ] 시작 화면과 플레이 안내 구성
- [ ] 고양이 기본 모습 및 필요한 표정 상태 디자인
- [ ] 이야기와 갈림길 화면 구성
- [ ] 전투 화면 구성: 플레이어/적 상태, 추천 행동, 행동 선택
- [ ] 선택에 따른 숲 분위기 변화 디자인
- [ ] 별자리 회고 화면과 선택 상세 보기 디자인
- [ ] 모바일 및 데스크톱 레이아웃 정리
- [ ] 키보드 포커스와 색상 외 상태 표시 반영

## 3. 구현

- [ ] 화면 전환과 게임 상태 관리 구현
- [ ] 미리 작성된 스토리 분기 데이터 연결
- [ ] 선택지 표시와 선택 결과에 따른 진행 구현
- [ ] AI 고양이 추천과 사용자 직접 선택 구현
- [ ] 턴제 전투 및 체력·아이템 처리 구현
- [ ] 선택 기록 및 재시작 시 초기화 구현
- [ ] 선택 누적에 따른 숲 분위기 변경 구현
- [ ] 선택 기록을 별자리형 경로로 시각화
- [ ] 선택 지점별 장면·행동 상세 표시
- [ ] 빈 아이템, 도주, 패배 등 예외 상태 처리

## 4. 콘텐츠 및 마감

- [ ] 시작 안내, 고양이 대사, 이야기 장면 작성
- [ ] 플레이 후 성찰 질문 작성
- [ ] 승리·도주·패배 이후 흐름 작성
- [ ] 웹 화면의 문구와 선택 결과 검토
- [ ] 사용성 확인을 진행하고 막히는 부분 기록
- [ ] 확인 결과를 바탕으로 알파 범위 개선
- [ ] 이미지 다운로드 또는 공유 기능 검토 (후순위)
