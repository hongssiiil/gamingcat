# Road 보드 반영

기준: 사용자가 제공한 `제목 없음.jam`, 이후 확정한 계획 및 지도 이동 정정.

## 진행

숲 탐색 → 4개 쪽지와 3142 암호 → 계약 → 주제 선택 → 갈림길 5회 → 완성 지도 → 지도 위 이동 → 연못 → 같은 지도 복귀 → 암벽 → 같은 지도 복귀 → 4번 두더지 튜토리얼 → 같은 지도 복귀 → 5번 늑대 전투.

경로 생성 이후에는 숲으로 돌아가지 않는다. 선택한 다섯 경로가 실제 이동 지도를 구성한다. 지도 1번째 지점에 연못, 3번째 지점에 암벽, 4번째 지점에 두더지 튜토리얼, 5번째 지점에 늑대를 배치했다. 완료하지 않은 장애물을 넘어갈 수 없으며, 퍼즐과 튜토리얼 완료는 현재 위치를 유지하고 다음 구간을 개방한다.

## 규칙과 조작

- 배경음악: 시작 화면·숲·갈림길 선택·완성 지도 보기까지 `Whispers of the Deepwood (Remastered)`, 지도 이동·두 퍼즐은 `Mysterious Forest Level`, 늑대 전투 결과 후 별자리는 `Constellation Watch`를 사용한다. 두더지·늑대 전투는 기존 전투 음악을 유지한다. 지도 음악은 튜토리얼 진입 시 일시정지하고 복귀 시 같은 재생 위치에서 이어진다. 같은 구간의 화면 갱신이나 퍼즐 열기/닫기로 음악을 재시작하지 않는다.
- 왼쪽 아래 픽셀 스피커 버튼에서 배경음악 음소거와 0~100% 음량을 조절한다. 전투 음악에도 동일한 설정을 적용하고 효과음은 유지한다. 설정은 로컬 저장소에 보관하며 팝업·튜토리얼 중에도 조작할 수 있다. 새 여정은 곡의 재생 위치를 초기화하되 음량 설정은 유지한다.
- 곡은 마지막 2초에 페이드 아웃하고 처음 1.5초에 페이드 인하며 반복한다. 브라우저가 자동 재생을 제한하면 첫 클릭이나 키 입력에서 다시 재생을 시도한다.

- 표지판 암호 팝업은 목재 프레임·나뭇결·리벳·이끼 장식과 네 개의 숫자 슬롯을 사용한다. 숫자 입력 시 다음 칸으로 이동하며, 빈 칸에서 Backspace를 누르면 이전 숫자를 지운다. 숫자 붙여넣기와 좌우 이동도 지원한다. 오답은 0.55초 흔들림·붉은 점멸 후 초기화하며 기존 PASSWORD 판정과 성공 흐름은 유지한다. 브라우저에서 자동 이동·Backspace·오답 초기화·정답 진행을 확인했고 기존 테스트 39개가 통과했다.

- 숲: WASD/방향키 이동, E 상호작용. 화면 이동 버튼으로 터치 조작도 가능하다.
- 쪽지는 수풀·바위에 숨겨져 있다. 가까이 가면 가장 가까운 조사 위치에만 E가 나타나고, E 또는 표시를 눌러 조사하면 해당 쪽지가 드러난다. 조사한 곳은 쪽지와 다시 읽기 표시를 유지하며 재방문으로 발견 기록이 중복되지 않는다.
- 갈림길: 하나의 픽셀 양피지 Canvas에 질문, 추천 메모, 발자국, 세 스탬프를 표시한다. 위/W · 오른쪽/D · 아래/S가 각각 1·2·3번 길이다. 터치나 마우스로 스탬프를 누르고 유지해도 같은 조작이 된다. 새 질문은 4초 뒤 자동 출발하며 입력하면 즉시 출발한다. Space/Escape 또는 지도 안 버튼으로 일시정지한다.
- 티니는 입력이 없으면 추천 길로 이끈다. 분기점 이후 다른 방향을 유지하면 속도가 45%로 줄고 목줄이 팽팽해진다. 1.6초 유지하면 티니가 수긍한다. 그 전에 놓으면 추천 쪽으로 돌아가며, 수긍 이후에는 선택한 길을 유지한다. 실제 발 위치를 잉크 궤적으로 저장하고 끝점에 도착해야 선택을 확정한다.
- 갈림길 도착 후에는 ARRIVED(0.8초) → PANNING(1.0초) → NEXT_FORK(0.6초) 순서로 이어진다. 한 Canvas를 계속 사용하고, 월드 구간 폭 540px만큼 카메라만 이동한다. 이전 도착점의 X/Y가 다음 출발점과 같으며 전환 중 방향 입력은 잠긴다. 5번째 도착 후에는 1.3초 동안 전체 경로와 선택한 다섯 랜드마크가 들어오도록 축소하고, 출발 버튼을 누르면 기존 탐험 지도로 진행한다.
- `completedPaths`에는 실제 걸어온 잉크의 월드 좌표를 저장한다. 카메라와 전환 상태도 저장해 전환 중 새로고침을 이어간다. 이 데이터가 없는 이전 저장은 선택 기록으로 기본 경로를 복원한다.
- 최종 요약은 같은 양피지 위에 침엽수·탐험 점선·물결·산맥·나침반을 세피아 워터마크로 표시한다. 실제 궤적은 화면 픽셀 단위의 굵기 변화와 번짐으로 재렌더링하고, 선택한 성곽·범선·항구·야영지 아이콘을 확대한다. 다섯 번호와 선택 라벨은 점선 아래 두 줄 이내로 정렬하며, 05 지점에 기존 플레이어·티니 에셋을 함께 표시한다. 압정 종이 출발 버튼은 키보드로도 작동하며 선택과 잉크 데이터를 보존한 채 지도 스테이지로 진행한다.
- 탐험 지도: A/D 또는 좌우 방향키로 저장된 실제 잉크 궤적을 따라 걷는다. 2~3개 구간이 보이는 확대 지도에서 카메라가 부드럽게 추적한다. 번호·선택 라벨·진행도 스탬프는 탐험 화면에서 표시하지 않는다. 지나온 거리의 최댓값을 저장해 뒤로 돌아가도 밝혀진 길을 유지하고, 앞쪽은 세피아 스케치에서 잉크로 드러난다.
- 미해결 1·3번에는 잉크가 끊긴 점선 슬롯·돌무더기·노란 느낌표를 표시한다. 4번 두더지와 5번 늑대에는 동일한 크기·명암의 기존 몬스터 에셋과 붉은 느낌표를 사용한다. 해당 노드 76 월드 픽셀 앞에서 자동 정지하고 2번은 그대로 통과한다. 정지 시 위험 빗금 배너와 하단 액션 버튼을 표시하며, E 또는 버튼으로 퍼즐이나 전투에 진입한다. 퍼즐 완료 후 현재 위치와 카메라를 유지하고 해당 구간의 잉크를 연결한다.
- 4번에서는 항상 두더지 튜토리얼 전투를 시작한다. 승리하면 같은 지도의 같은 위치로 복귀하고 `completed`에 `tutorial`을 저장해 5번을 개방한다. 도망은 완료로 처리하지 않는다. 완료 후 새로고침해도 유지되며 새 여정에서는 다시 진행한다. 5번은 페이지의 임시 튜토리얼 플래그와 관계없이 늑대 전투를 시작한다. 지도 복귀 시 튜토리얼 안내·입력 제한을 해제한다.
- 탐험 UI는 픽셀 Canvas이며 숲·물결·산맥 워터마크, 움직임에 반응하는 나침반, 도트 발자국과 티니 경계 동작을 포함한다. 좁은 화면에서는 Canvas 논리 폭을 조정하고 터치 환경에 좌우 이동 버튼을 제공한다.
- 1·3번의 `구간 갈아끼우기 [E]`는 각각 4×4 연못·암벽 퍼즐을 연다. 열 때마다 무작위 DFS로 시작 칸 0부터 모든 16칸을 한 번씩 방문하는 경로를 만들고, 다음 칸의 위치에서 힌트를 역산한다. 연못은 직선 1~3칸 점프만 사용하고 마지막 칸을 15로 고정한다. 암벽은 서로 다른 어떤 칸으로든 이동할 수 있으며 가로·세로 거리로 두 자리 숫자를 만든다. 마지막 칸의 숫자도 유효한 이동 거리로 채운다. 판과 정답 경로는 `puzzleBoards`에 저장하며 표시·클릭·도움말이 같은 판을 사용한다. 기존 `POND`/`CLIMB` 배열은 이전 저장의 진행 중인 고정 판을 복원하는 용도로만 남긴다.
- 퍼즐 진행 중에는 경고 배너와 진입 버튼을 숨기고 카메라·플레이어·티니의 기준 위치를 고정한다. ‘다시’와 오답에 의한 초기화는 같은 판의 진행만 0/16으로 되돌린다. X/ESC로 닫으면 원래 막힘 상태를 복구하며, 다시 열면 새 무작위 판과 0/16 진행으로 시작한다. 열린 채 새로고침하면 판·카메라·진행을 그대로 복원한다. `onPuzzleSuccess(nodeId)`는 중복 없는 16칸의 실제 이동 경로가 유효할 때만 노드를 해제한다. 패널을 닫고 돌·느낌표를 제거하며 잉크를 연결한 뒤, 먼지 효과와 티니의 0.5초 점프를 재생하고 이동을 재개한다.
- 연못: 현재 돌의 방향으로 표시된 거리만큼 이동한다. 발바닥 1개(거리 1)인 칸은 판 전체에서 최대 2개로 제한한다. DFS 경로 생성 중 해당 이동 수를 제한하며 시작 0 → 도착 15의 중복 없는 16칸 완주를 보장한다. 제한을 넘는 미완료 저장 판은 새 판의 0/16으로 교체하고, 완료 기록과 여정은 보존한다. ‘다시’는 같은 판의 진행만 초기화한다.
- 바위 발판 오르기: 십의 자리는 좌우 거리, 일의 자리는 상하 거리이며 0인 축은 이동하지 않는다. 무작위 DFS는 해당 숫자로 갈 수 있는 격자 내 목적지가 정확히 하나인 이동만 사용한다. 방문 여부로 후보를 줄이지 않아도 숫자만으로 다음 칸을 결정할 수 있다. `11`은 판 전체에서 최대 2개이며, 16칸 완주 경로와 마지막 칸의 유효한 더미 숫자를 유지한다. 모호한 미완료 저장 판은 새 판의 0/16으로 교체하고, 여정·완료된 장애물 기록은 보존한다.
- TOKEN 15로 시작한다. hint/plan/solve 비용은 1/3/8이다. 음수 잔액을 허용하며 부족한 토큰 수를 AI DEBT로 표시한다.
- 티니는 오른쪽 아래에 있다. 누르면 화면을 어둡게 하지 않는 채팅 패널이 열리고, 플레이어가 `/hint`, `/plan`, `/solve`를 직접 입력한다. Enter는 전송, Shift+Enter는 줄바꿈, Escape는 닫기다. 명령 오타와 일반 메시지는 안내 답변만 제공하고 토큰을 사용하지 않는다. 대화 중 이동과 고민 시간 집계를 일시 중지하며, 기존 도움 기록도 대화로 표시한다.
- AI는 사전 작성 응답이다. 새 주제 선택은 연애·진로·자기실현의 세 카드만 제공한다. 과거 기타 주제 저장 데이터는 복원 호환성을 유지한다.
- 서약 거절은 같은 양피지에서 흔들림과 티니의 준비 안내를 표시하며 다시 동의할 수 있다.
- 도입부는 중앙 정렬한 백지 지도 안내 → 서약서 → 세 갈래 선포서로 이어진다. 기존 티니 에셋, 픽셀 Canvas 아이콘, 잉크 번짐·밀랍 인장·짧은 도장 소리와 A/D·좌우 키 카드 탐색을 사용한다.
- 암호 해제 뒤 경로 안내, 서약, 주제 선택은 기존 숲과 플레이어 위치를 유지한 양피지 팝업으로 이어진다. 팝업 중에는 숲 조작을 막고, 주제 선택을 마친 뒤 갈림길 화면으로 전환한다.

## 구현 경계

숲 화면은 상하 바 없이 전체 화면으로 표시하며, 카메라는 화면을 덮는 배율로 플레이어를 따라간다. 토큰과 HELP는 맵 위 HUD로 배치한다. Road의 버튼은 픽셀 프레임, 대화창은 기존 양피지 자산을 사용하며 쪽지·발바닥은 자체 도트 아이콘을 사용한다. 모바일 조작은 HELP와 겹치지 않는 십자 패드다. 화면 전환 탭의 픽셀 스타일은 Road가 활성화된 동안에만 적용한다.

- `script/road.js`: 화면, 조작, 카메라, 전환, 도움 인터페이스.
- `script/road/introduction.js`: 도입부 세 양피지 문서, 픽셀 아이콘, 서약 피드백, 카드 키보드 탐색과 확정 연출.
- `script/road/content.js`: 보드 쪽지, 4개 주제별 5회 질문, 두 퍼즐의 판, 지도 장애물 위치.
- `script/road/collision.js`: 원본 배경(1023×769)의 픽셀 좌표로 정의한 숲 외곽, 검은 나무 섬, 바위·나무·표지판의 발밑 충돌 영역. 캐릭터 발의 작은 범위로 이동을 판정하고, 기존 저장 위치가 새 장애물과 겹치면 가장 가까운 보행 위치로 옮긴다. `?collisionDebug=1`은 동일한 충돌 데이터를 화면에 표시한다.
- `script/road/occlusion.js`: 배경의 바위·나무 실루엣을 SVG 클립으로 다시 그리는 앞쪽 레이어. 플레이어 발이 오브젝트 밑동보다 위에 있으면 가리고, 밑동 앞으로 나오면 가림을 해제한다. 표지판도 같은 깊이 순서를 사용하며 충돌 도형과 가림 실루엣은 독립적이다.
- `script/road/ink-map.js`: 픽셀 Canvas 지도와 스탬프·추천 메모·잉크·목줄 렌더링. 기존 캐릭터 에셋과 양피지를 사용하며 imageSmoothingEnabled를 끈다.
- `script/road/journey.js`: 도착·패닝·새 갈림길·전체 보기 상태 머신, 월드 경로 저장과 이전 저장 복원.
- `script/road/exploration.js`: 실제 잉크의 거리 표, 위치 보간, 장애물 정지 거리와 빈 슬롯, 발견 범위, 카메라 추적과 동행·발자국 상태. 이전 SVG 지도의 저장 위치는 같은 구간의 새 거리로 변환한다.
- `script/road/puzzle-flow.js`: 노드 1/3을 기존 퍼즐에 연결하는 열기·취소·성공 어댑터. 기존 `finishPuzzle` 판정을 재사용하며 퍼즐 데이터나 해법을 새로 정의하지 않는다.

## 이전 구현 기록

아래 갈림길 창·조작 기록은 통합 잉크 지도 리팩토링 이전의 이력이다. 현재 동작은 위 규칙을 따른다.

최근 수정: 갈림길도 암호를 풀던 숲 배경과 카메라 위치를 유지한다. 선택 클릭은 선택 표시만 바꾸며, 이동 입력이 들어오면 질문·추천 창이 닫힌다. 선택 전에는 모든 항목이 같은 색이다. 추천 경로에서는 티니가 앞서고, 다른 길에서는 뒤따른다. 다음 갈림길은 숲을 유지하면서 기존 경로 창을 0.45초 동안 퇴장시키고 새 창을 서서히 표시한다. 브라우저에서 창 유지/이동 시 닫힘, 티니 선행 좌표, 다음 질문의 선택 초기화를 확인했다.

갈림길 조작 변경: 선택지 버튼과 숫자 선택 단계를 제거했다. 질문 창의 세 항목은 안내 문구이며, 위/아래 방향 입력은 해당 갈래로 걷기 시작하고 오른쪽은 앞으로, 왼쪽은 뒤로 걷는다. 움직이면 팝업이 접히며, 길 끝 도착 시에만 선택 기록을 확정한다.

지도 화면 수정: summary/map도 기존 숲 배경 위에 양피지 대화창 자산을 사용한 지도 패널로 표시한다. 격자를 제거하고 갈색 길·이정표·방위 표시를 사용한다. 선택지 전문 대신 번호를 표시해 노드 글자 겹침을 줄였으며 전체 선택 기록은 요약의 펼침 영역에 유지한다. 지도 이동과 구역 진입 규칙은 그대로다. 이번 수정은 문법 검사 및 규칙 테스트 14개로 검증했으며 브라우저 시각 검증은 수행하지 않았다.

연못 퍼즐 수정: START를 포함한 16칸을 정해진 순서로 클릭한다. 정답 칸은 흰색으로 유지되고, 흰 칸이 0~3개인 동안의 오답은 진행을 유지한다. 흰 칸이 4개 이상일 때 오답 또는 중복 클릭은 전체를 초기화한다. 발자국 방향과 개수가 다음 이동 방향·거리를 나타내며 화살표와 숫자는 판에서 제거했다. 판 최대 폭은 700px이다. 선택 기록은 저장·복원되며 구형 저장의 연못 시도만 초기화한다. 암벽 규칙과 Battle은 그대로다. 관련 테스트 18개 통과, 브라우저에서 새 판의 진입 및 버튼 라벨은 확인했으나 이후 화면 상태가 달라져 흰색 클릭 시각 검증은 완료하지 못했다.

암벽 퍼즐 수정: 두 자리는 가로·세로 변위를 동시에 적용한다. 12의 좌우 1칸 및 상하 2칸 조합은 네 방향이며, 경계 밖과 제자리 이동은 제외한다. 10은 같은 행에서 좌우 1칸이다. START부터 서로 다른 16칸을 전부 흰색으로 채워야 완료되고 지정 EXIT는 없다. 연못과 같은 700px 크기, 흰색 진행 표시 및 0~3칸 오답 유지/4칸 이상 오답 초기화를 적용했다. 힌트 해법은 방문 기록을 고려한 전체 방문 경로를 구한다. 참조 순서 12→22→13→22→32→23→13→12가 일치하며 전체 완주, 저장 복원, 오답 경계 등 테스트 22개가 통과했다. 이번 변경의 브라우저 시각 검증은 수행하지 않았다.

연속 지도 전환 검증: 28개 규칙 테스트 통과. 서로 다른 높이의 다섯 경로 연결, 0.8/1.0/0.6초 전환 순서, 입력 잠금, 중복 확정 방지, 전환 저장 복원, 전체 지도 카메라 범위를 확인했다. 브라우저에서 다섯 단계 완주, 패닝 중 새로고침, 최종 전체 지도 표시를 확인했다.
