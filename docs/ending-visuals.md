# 별자리 회고 시각 연출

- 추천을 따른 기록은 바랜 황동색, 직접 고른 기록은 회색빛 청록색, 비교할 수 없는 기록은 중립 별로 표시한다. 기존 기록과 세 결과별 고양이·나침반·여행자 워터마크를 유지한다.
- 추가했던 대각 은하수, 성운 블록과 중앙의 뿌연 입자를 모두 제거했다. 원래 밤하늘 그라데이션 위에는 1~2px 도트 잔별 100개만 드문드문 배치한다. 각기 8~16초 주기로 반짝이며, 약 35%는 밝기 변화가 조금 더 뚜렷하다.
- 7초의 진입 연출 동안 별 자체가 연결선의 끝과 함께 다음 위치로 이동하고 정착한다. 아직 도착하지 않은 별은 미리 표시하지 않는다. 이후 선은 고정된 반투명 실선으로 남는다. 반복 이동 펄스는 없다. 선택지 별은 각기 약 4.8~7.4초 주기로 제자리에서 밝기가 30~100% 범위로 부드럽게 변하고 글로우도 함께 숨쉬며, 호버·키보드 포커스·카드 선택 때만 강한 빛을 표시한다.
- 유성은 2.2~3.2초 동안 빠르게 흐르며 15~18픽셀 길이의 꼬리를 남긴다. 흐른 뒤 2~4초의 불규칙한 간격을 두고 다시 나타난다. 위치·방향·속도가 서로 다르다. 누적 토큰 사용량이 0~10개면 16개 레인에 밝게 그려지고, 11~20개면 그 절반인 8개를 표시한다. 각 레인은 하늘 전체에 나뉘어 유성이 서로 겹치지 않게 배치된다.
- 누적 사용량 21~30개는 유성 대신 드문드문 픽셀 토큰이 수직 낙하하고, 31개 이상은 토큰 수와 반복 빈도가 늘어난다. 토큰 구간은 선택의 평가나 판정으로 표현하지 않는다. 토큰 낙하와 유성은 모션 감소 및 PNG 저장에서 정지한다.
- 원본 도트 좌표에 맞춘 굴뚝 연기, 고양이 눈 깜빡임·느린 꼬리, 망토·풀잎·나무의 작은 흔들림과 하단 반딧불이를 유지한다. 창문은 밝은 유리 부분에만 따뜻한 색을 아주 미세하게 겹쳐 일렁이게 한다.
- 모션 감소 설정과 PNG 저장은 정적인 장면을 사용한다. 기록 열기, 테마 판정과 하단 버튼 간격은 유지한다.

구현: script/ending-effects.js(사용량 구간·토큰 낙하), script/ending-art.js(밤하늘·별·유성·고정선), script/ending-diorama.js(전경), script/ending.js(조합·상호작용).

기존 검증: 유성 간격·다양성·반복 경계, 성운 없는 1~2px 잔별, 별과 선의 동시 이동, 도착 전 숨김과 완료 후 고정, 제자리 숨쉬기, 잔별 밝기 변화와 모션 감소 동작을 확인했다. 브라우저에서 예시 기록으로 별자리와 기록 카드 선택도 확인했다.

이번 변경 검증: 엔딩 관련 테스트 24개 통과. 구간 경계와 구간별 유성·토큰 밀도, 모션 감소의 정지 렌더링을 확인했다. 브라우저에서 임시 엔딩 이동 버튼으로 유성 및 토큰 화면을 확인했고, 360px 뷰포트에서 기록 버튼 접근성을 확인했다. PNG 다운로드 자체는 다시 확인하지 않았다. 전체 테스트는 94개 통과, 기존 미커밋 전투 튜토리얼 변경과 관련된 3개 실패다.
