# 여정 공용 토큰과 road 화면

새 여정은 20개로 시작한다. road 도움과 두더지·늑대 전투 도움은 같은 잔액과 events에 기록하며 화면에는 남은 토큰만 표시한다. 배틀 진입, 지도 복귀와 패배 후 재도전은 재지급하지 않는다. 새 여정에서만 20개로 초기화하며 전투 상태도 함께 정리한다.

기존 10개 시작 저장은 tokens에 10개를 보태고 tokenBudgetVersion을 기록해 중복 이전을 막는다. 이전 사용량과 진행 상태는 보존한다. 과거 버전에서 별도 메모리에만 있던 전투 지출은 저장되어 있지 않아 복구하지 않는다.

script/road/model.js: 초기 지급량·저장 이전. script/road.js와 script/battle.js: 현재 여정 상태를 가리키는 공용 잔액. script/battle/flow.js: 재지급 제거 및 지출 즉시 저장. script/battle/token.js: 잔액 표시. script/main.js: 새 여정의 전투 초기화.

style/road.css: 양피지 팝업 뒤 어두운 배경, 갈림길·지도 뒤 숲 밝기 조정, 기능 버튼의 각진 픽셀 테두리와 나무색. 지도 스탬프와 퍼즐 타일 자체의 디자인은 유지한다.

검증: 관련 테스트 15개 통과. 브라우저에서 새 여정 20 → road 도움 19 → 배틀 확률 조회 18 → 새로고침 후 road 18 → 새 여정 20을 확인했다. 남은 토큰만 보이며 양피지 배경과 버튼을 확인했고 콘솔 오류가 없었다. 실제 모바일 기기 검증은 수행하지 않았다.
