# gaming cat — 완료 체크리스트

## 알파 출시 전 필수

### 시작과 진행

- [ ] 시작 화면에서 게임 목적과 시작 방법을 알 수 있다.
- [ ] 안내를 읽고 이야기 진행 및 전투 조작을 이해할 수 있다.
- [ ] 첫 화면부터 결말과 회고 화면까지 진행이 끊기지 않는다.
- [ ] 갈림길에서 선택지를 고르면 해당 선택에 맞는 다음 장면으로 이동한다.
- [ ] 다시 시작하면 이전 플레이 선택이 남지 않는다.

### 고양이와 선택

- [ ] 고양이 캐릭터가 게임 흐름에서 일관되게 보인다.
- [ ] 고양이의 추천과 사용자의 선택이 구별된다.
- [ ] 사용자는 추천을 따르거나 다른 선택을 할 수 있다.
- [ ] 선택 결과가 이후 이야기 또는 게임 상태에 반영된다.
- [ ] 선택 방식에 점수나 도덕적 평가를 붙이지 않는다.

### 턴제 전투

- [ ] 전투에서 플레이어와 적의 체력을 확인할 수 있다.
- [ ] 플레이어와 적의 턴이 순서대로 진행된다.
- [ ] 공격, 도망, 아이템 사용이 정상적으로 처리된다.
- [ ] 체력 변화와 아이템 수량이 행동 결과에 맞게 반영된다.
- [ ] 적 처치, 도주, 플레이어 패배가 각각 처리된다.
- [ ] 아이템이 없거나 행동을 할 수 없는 경우 진행이 막히지 않는다.

### 숲과 별자리 회고

- [ ] 누적된 선택이 숲의 분위기에 눈에 보이게 반영된다.
- [ ] 마지막 화면에 이번 플레이의 선택 경로가 별자리 형태로 나타난다.
- [ ] 별자리의 순서와 연결을 통해 선택 흐름을 이해할 수 있다.
- [ ] 각 선택 지점에서 당시 장면과 선택 내용을 확인할 수 있다.
- [ ] 회고 질문이 사용자의 생각을 돕고 결론을 강요하지 않는다.

### 화면과 조작

- [ ] 모바일과 데스크톱에서 주요 화면과 버튼이 잘 보인다.
- [ ] 키보드로 주요 선택과 진행 동작을 사용할 수 있다.
- [ ] 키보드 포커스 위치를 확인할 수 있다.
- [ ] 체력이나 진행 상태가 색상만으로 전달되지 않는다.
- [ ] 긴 텍스트와 불분명한 버튼 문구가 없다.

## 알파 이후 검토

- [ ] 여정 이미지를 기기에 저장할 수 있다.
- [ ] 개인정보를 포함하지 않고 여정을 공유할 수 있다.
- [ ] 추가 이야기 분기와 전투 콘텐츠가 확장 가능하다.
- [ ] 사용성 확인에서 관찰된 문제를 반영했다.
